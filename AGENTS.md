# Инструкции для работы с проектом

- Соблюдать `Development Requirements.md`.
- При новой задаче прочитать `AI Workflow.md` и вести работу по нему.
- Дизайн нового кода выводить из требований задачи и смысла предметных сущностей. Наличие решения в существующем коде само по себе не означает, что оно одобрено пользователем.
- Служебные инструменты разработки и отладки каждого демо хранятся в `utils/<имя_демо>/` (например, `utils/nehopio/`): генераторы ассетов и звуков, проверки карт, отладочные скрипты и утилиты. При работе над демо сначала проверять эту папку и переиспользовать готовые инструменты.
