# NeuexpEngine

Экспериментальный 2D-движок на C++17 и OpenGL 1.1 для Windows и Linux.
Его пишет нейронка: задачи простые — небольшие игры и демонстрационные сцены,
поэтому в движке нет лишних слоёв, скрытых подсистем и зависимостей из сети.

## Что уже есть

- **Окно и ввод** — одно окно, которое можно растягивать, фиксированный размер тоже
  поддерживается; клавиатура с удержанием и повтором, мышь с кнопками и колесом,
  корректная потеря фокуса. Одинаково на Windows и Linux.
- **Игровой цикл** — события, обновление, отрисовка и показ кадра разделены; есть FPS,
  тайминги частей кадра, ограничение FPS, вертикальная синхронизация и пауза. После
  паузы или свёрнутого окна симуляция не прыгает вперёд. Приложение может включить
  постоянный шаг симуляции: накопитель времени и предел догоняющих шагов делают
  результат воспроизводимым и не дают кадру догонять долгую задержку.
- **Математика и камера** — векторы, углы, прямоугольники и цвета, преобразования
  с поворотом, масштабом и точкой вращения, пересечения фигур. Камера умеет масштаб
  и перевод мира в экранные координаты; интерфейс живёт в своих координатах и учитывает
  системный DPI.
- **Рисование** — точки, линии, прямоугольники, круги, эллипсы и многоугольники,
  контуром и с заливкой, с прозрачностью и слоями. Порядок команд стабильный, есть
  отсечение по видимой области, а в коде игры нет ни одного заголовка OpenGL.
- **Ресурсы** — файлы читаются из одного каталога независимо от того, откуда запущена
  игра; PNG декодируется через stb_image, текстуры кешируются, повреждённый файл даёт
  понятную ошибку вместо падения.
- **Спрайты и атласы** — спрайт из целой картинки или её куска, поворот, масштаб, цвет
  и прозрачность; атлас описан текстовым файлом с именами областей; попадание мышью
  в спрайт проверяется точно по прозрачным пикселям.
- **Анимация** — наборы кадров с темпом, пауза и перезапуск, однократный и циклический
  режимы с удержанием последнего кадра; кадры берутся из атласа по именам, а клипы
  вроде «бег» и «прыжок» собираются в набор и переключаются по названию.
- **Текст** — растровые шрифты с латиницей и кириллицей: UTF-8, перенос по словам,
  выравнивание, цвет и масштаб, измерение размера до рисования, понятное поведение
  для отсутствующих глифов.
- **Интерфейс** — кнопки и текстовые кнопки, флажки, подписи, индикаторы прогресса
  и цифровые индикаторы; состояния наведения и нажатия, группы элементов, переключение
  экранов меню. Масштаб интерфейса настраивается отдельно от масштаба мира.
- **Сцены и объекты** — сцена держит объекты в порядке добавления и обновляет их одним
  проходом; у объектов есть идентификаторы, имена и группы, поиск, видимость и
  отложенное удаление, поэтому удалять можно прямо во время обновления сцены. У сцены
  своя камера, а удаление экземпляра не освобождает текстуру, которой пользуются другие.
- **Столкновения и контакты** — круг, прямоугольник вдоль осей и повёрнутый
  прямоугольник: пересечения с нормалью и глубиной проникновения, попадание точки,
  расстояние между формами, а также луч и отрезок по любой из них. Слои и маски отсекают
  ненужные пары, триггеры сообщают о контакте без отталкивания, а события начала,
  продолжения и завершения приходят по одному на пару — даже когда объект удалён или
  сцена очищена.
- **Физика** — неподвижные, динамические и кинематические тела с круглыми и
  прямоугольными формами: масса, плотность, инерция, гравитация, затухание, трение и
  упругость, силы и импульсы в точке, вращение. Столкновения разрешаются с ограниченным
  числом итераций, сенсоры сообщают о контакте без отталкивания и отдают импульс удара,
  а удаление тел отложено и безопасно во время обработки событий. Состояние тел
  переводится в трансформации объектов сцены, с этой же сценой работают спрайты.
- **Дальше по плану** — сценарии поведения, настройки с локализацией, звук
  и сквозная приёмка движка.

## Сборка

Нужны CMake 3.16 или новее, компилятор C++17 и драйвер с поддержкой OpenGL 1.1.

### Windows

Установите MinGW-w64: `cmake`, `g++` и `mingw32-make` должны быть в `PATH`.

```powershell
.\scripts\build_demos.bat
```

### Linux

```sh
sudo apt install build-essential cmake libx11-dev libgl1-mesa-dev
./scripts/build_demos.sh
```

Исходники stb_image и miniaudio лежат в `third_party/`, поэтому сборка не скачивает
зависимости из сети. В Linux для miniaudio нужны системные библиотеки потоков, `dl`
и `m`. Собранные приложения появляются в каталоге `build/`.

Тесты собираются и запускаются через `./scripts/build_and_run_tests.sh` или
`.\scripts\build_and_run_tests.bat`: команда собирает движок с тестами и сразу
прогоняет их.

Для очистки результатов сборки используйте `./scripts/clean.sh` или
`.\scripts\clean.bat`: скрипты можно запускать из любой папки.

## Исходники

- `engine/` — код движка; собирается в одну библиотеку `neuexpengine`, отдельно лежит
  только точка входа `neuexpengine_entry_point`.
- `platform/` — окна, ввод и поиск каталога ресурсов для Windows и Linux.
- `demos/` — примеры и демонстрационные приложения на движке.
- `tests/` — автотесты и их ресурсы.
- `assets/` — ресурсы демонстрационных приложений.
- `third_party/` — stb_image и miniaudio.
- `scripts/` — сборка, очистка и тесты для Windows и Linux.
- `CMakeLists.txt` — настройка сборки.
