# NeuexpEngine

Экспериментальный 2D-движок на C++17 и OpenGL 1.1 для Windows и Linux.
Его пишет нейронка: задачи простые — небольшие игры и демонстрационные сцены,
поэтому в движке нет лишних слоёв, скрытых подсистем и зависимостей из сети.

## Что уже есть

**Основа проекта.** CMake и C++17, сборка Release, строгие предупреждения компилятора,
четыре самостоятельные части: платформенные реализации, ядро движка, автотесты и
демонстрационные приложения. Исходники stb_image и miniaudio лежат в `third_party/`,
сборка ничего не скачивает.

**Платформенный слой.** Создание и уничтожение окна, инициализация и освобождение
контекста OpenGL, обработка частичной ошибки запуска. Заголовок окна, размер
клиентской области, изменение размера и два режима окна: фиксированный и изменяемый
пользователем, с минимальными размерами. События закрытия, фокуса, сворачивания и
восстановления; управляемый выход. Реализации для Win32/WGL и X11/GLX; нативный
Wayland не поддерживается.

**Ввод и события.** Клавиатура с удержанием, нажатием и отпусканием, повтором и
вводом символов; мышь с положением, кнопками и колесом. Нативные сообщения
превращаются в общие события движка с сохранением порядка; снимок состояния
показывает итог после обработки, удержания сбрасываются при потере фокуса.
Отдельный необязательный слой подписок вызывает обработчики с предсказуемым
порядком и безопасным изменением списка во время обработки.

**Приложение и время.** Чётко разделённые события, обновление симуляции,
подготовка кадра, отрисовка и показ. Монотонные часы, FPS и тайминги частей кадра.
Одно обновление мира на кадр с переменным `dT`; после паузы, сворачивания или
долгой задержки скачка симуляции нет. Независимые ограничение FPS и вертикальная
синхронизация, явная пауза и определённый порядок запуска и очистки подсистем.

**Математика и камера.** Векторы, размеры, цвета, прямоугольники и углы; положение,
поворот, масштаб и точка вращения с прямыми и обратными преобразованиями;
пересечения фигур и попадание точки в область. Согласованные системы координат
мира, экрана и интерфейса с учётом системного DPI. Камера с положением и масштабом,
переводом координат мира в экранные и обратно; при смене пропорций окна обзор
расширяется по выбранному правилу.

**Рисование.** Точки, линии, прямоугольники, окружности, эллипсы и многоугольники —
контуром и заливкой, с цветом, прозрачностью и преобразованиями. Стабильная
сортировка команд по слою и порядку внутри вида, отсечение по видимой области,
конвейер кадра «мир → интерфейс». Публичный API без типов и заголовков OpenGL.

**Ресурсы.** Единый каталог ресурсов и чтение текстовых и бинарных файлов
независимо от рабочей директории. Декодирование PNG через stb_image в RGBA8 с
проверкой ошибок до создания ГПУ-ресурсов. Текстуры с фильтрацией и обращением
к краям, кеш изображений без дублей в видеопамяти, защита от повреждённых файлов.

**Спрайты и атласы.** Спрайт из целой текстуры или её прямоугольного участка;
координаты текстуры не зависят от размера на экране. Положение, масштаб, поворот,
точка вращения, видимость, цвет и альфа. Именованные области атласа с простым
текстовым описанием, несколько кадров одной сущности в общем атласе, попадание
точки в спрайт с точной проверкой по альфа-каналу.

**Анимация.** Наборы кадров с общей или индивидуальной длительностью, текущий кадр
и прошедшее время, воспроизведение, пауза, остановка и перезапуск, однократный и
циклический режимы с удержанием последнего кадра и флагом завершения, скорость,
несколько независимых анимаций одновременно. Кадры берутся из атласа по именам,
клипы одного объекта собраны в набор и переключаются по имени.

**Текст.** Растровый шрифт: PNG-атлас глифов и текстовое описание метрик. UTF-8
с латиницей, кириллицей, цифрами и знаками препинания, вывод строки и нескольких
строк, перенос по словам, выравнивание, цвет и масштаб, измерение размеров до
рисования, понятное поведение для отсутствующих глифов и некорректного UTF-8.

**GUI.** Общий механизм элементов: кнопки, текстовые кнопки, флажки-переключатели,
подписи, индикаторы прогресса и цифровые индикаторы; состояния наведения, нажатия,
отпускания и отключения; события взаимодействия без зависимости от ОС; группы
элементов и переключение экранов меню. Масштаб интерфейса задаётся отдельно от
масштаба мира, изменение окна не сбивает выбранный масштаб.

Дальше по `road map.md` — сцены и жизненный цикл объектов, столкновения, физика,
сценарии поведения, настройки с локализацией, звук и сквозная приёмка движка.

## Слои

Движок собран из небольших статических библиотек, имя цели — `neuexpengine_<слой>`:

| Слой | Что внутри |
| --- | --- |
| `neuexpengine_math` | векторы, геометрия, преобразования |
| `neuexpengine_camera` | камера и виды |
| `neuexpengine_ui` | канвас и экранный вид |
| `neuexpengine_events` | события и подписки |
| `neuexpengine_time` | часы кадра |
| `neuexpengine_resources` | файлы ресурсов и PNG |
| `neuexpengine_renderer` | рендер 2D, текстуры, спрайты, атласы, анимации, текст |
| `neuexpengine_gui` | элементы GUI и контекст |
| `neuexpengine_application` | цикл приложения |
| `neuexpengine_entry_point` | точка входа |

Заголовки подключаются по имени файла (`renderer.h`, `atlas.h`), весь API живёт
в пространстве имён `NeuexpEngine`.

## Сборка

Нужны CMake 3.16 или новее, компилятор C++17 и драйвер с поддержкой OpenGL 1.1.

### Windows

Установите MinGW-w64: `cmake`, `g++` и `mingw32-make` должны быть в `PATH`.

```powershell
.\scripts\build.bat
```

### Linux

```sh
sudo apt install build-essential cmake libx11-dev libgl1-mesa-dev
./scripts/build.sh
```

Исходники stb_image и miniaudio лежат в `third_party/`, поэтому сборка не скачивает
зависимости из сети. В Linux для miniaudio нужны системные библиотеки потоков, `dl`
и `m`. Собранные приложения появляются в каталоге `build/`.

Для очистки результатов сборки используйте `./scripts/clean.sh` или
`.\scripts\clean.bat`: скрипты можно запускать из любой папки.

## Тесты

```sh
./scripts/test.sh      # Linux
.\scripts\test.bat     # Windows
```

Тесты собираются через CTest и покрывают математику и геометрию, камеру, рендер
и текстуры, текст и шрифты, ресурсы, события ввода, GUI, очистку и VSync;
отдельные наборы проверяют платформенные слои Windows и Linux.

## Исходники

- `engine/` — код движка по слоям.
- `platform/` — окна, ввод и время для Windows и Linux.
- `demos/` — примеры и демонстрационные приложения на движке.
- `tests/` — автотесты и их ресурсы.
- `assets/` — ресурсы демонстрационных приложений.
- `third_party/` — stb_image и miniaudio.
- `scripts/` — сборка, очистка и тесты для Windows и Linux.
- `CMakeLists.txt` — настройка сборки.
