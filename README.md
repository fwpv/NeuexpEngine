# ogl_demo

Небольшое интерактивное 2D-демо на C++17 и OpenGL 1.1 для Windows и Linux.
Управляйте кораблём, стреляйте по дронам и перемещайтесь через порталы на космической сцене.

## Что внутри

- Игровая сцена с кораблём, станцией, дронами и порталами.
- Отрисовка геометрическими примитивами OpenGL.
- Работа с окном и клавиатурой через Win32/WGL в Windows и X11/GLX в Linux.
- Сборка через CMake.

## Сборка и запуск

Нужны CMake 3.16 или новее, компилятор C++17 и драйвер с поддержкой OpenGL 1.1.
Выполняйте команды из каталога проекта.

### Windows

Установите MinGW-w64. Команды `cmake`, `g++` и `mingw32-make` должны быть доступны в `PATH`.
В PowerShell:

```powershell
.\scripts\build.bat
.\build\circle.exe
```

### Linux

Нужны GCC или Clang, Make, библиотеки разработки X11 и OpenGL/GLX.
В Debian/Ubuntu зависимости можно установить так:

```sh
sudo apt install build-essential cmake libx11-dev libgl1-mesa-dev
```

Соберите и запустите приложение:

```sh
./scripts/build.sh
./build/circle
```

Исходники stb_image и miniaudio уже включены в репозиторий; сборка не скачивает
зависимости из сети. В Linux для miniaudio также используются системные библиотеки
потоков, `dl` и `m`; для воспроизведения потребуется доступный аудиобэкенд.

Для запуска нужна графическая сессия X11 или XWayland. Нативный Wayland не поддерживается.

Для очистки результатов сборки выполните `./scripts/clean.sh` в Linux
или `.\scripts\clean.bat` в Windows. Скрипты сборки и очистки можно запускать
из любой папки: пути вычисляются относительно расположения скриптов.

## Исходники

- `engine/` — общие интерфейсы и платформонезависимый код движка.
- `platform/` — реализации для Windows и Linux.
- `demos/circle/` — точка входа, игровая логика и отрисовка демо.
- `tests/` — автоматические тесты и их ресурсы.
- `assets/` — ресурсы демонстрационных приложений.
- `third_party/` — локальные исходники stb_image и miniaudio.
- `scripts/` — скрипты сборки, очистки и запуска тестов для Windows и Linux.
- `CMakeLists.txt` — настройка сборки.
