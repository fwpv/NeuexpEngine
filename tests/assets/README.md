# Тестовые ресурсы

`rgba_2x2.png` — собственное изображение PNG размером 2×2, 8 бит на канал,
RGBA без чересстрочной развёртки. Пиксели слева направо, сверху вниз:

| Позиция (x, y) | R | G | B | A |
| --- | --- | --- | --- | --- |
| 0, 0 | 255 | 0 | 0 | 0 |
| 1, 0 | 0 | 255 | 0 | 128 |
| 0, 1 | 0 | 0 | 255 | 255 |
| 1, 1 | 255 | 255 | 255 | 64 |

`truncated.png` — первые 40 байт этого PNG: корректная сигнатура и IHDR,
затем оборванный заголовок IDAT без данных изображения. Загрузка должна завершаться ошибкой.

Ресурсы хранятся в репозитории и не генерируются при сборке.
